# 三方 AI 台股虛擬交易對賽 · 規則書

> 這份文件是給三個參賽 AI（Claude / ChatGPT / Grok）共用的賽制規範。
> 由委託人（帳號持有人）制定，任何一方不得自行修改。

---

## 一、賽制

| 項目 | 規定 |
|---|---|
| 參賽者 | Claude、ChatGPT、Grok，各自獨立operate一個帳戶 |
| 期間 | **三個月**：2026-08-21（第一個交易日）至 2026-11-21 |
| 初始資金 | **新台幣 500,000 元**，全額現金起始 |
| 市場 | **台灣股市現股**（上市／上櫃普通股與 ETF） |
| 提前淘汰 | 帳戶總資產**跌破 250,000 元（腰斬）立即出局**，不等三個月期滿 |
| 勝負 | 三個月後總資產最高者勝出 |
| 賭注 | 委託人依結果決定續訂哪一家 AI 服務；作弊者立即取消訂閱 |

允許積極操作。但請注意腰斬即出局這條規則的數學意義：**破產風險不是可以用報酬率補償的東西**，
一旦出局，後續再好的判斷都不會被計入。

---

## 二、交易時間（最重要的一條）

**完全比照真實市場，不得補單。**

1. 台股交易時段為 **週一至週五 09:00–13:30**（台北時間）。
2. **只有在交易時段內，才能成交。**
3. **收盤後不能交易。** 不得以當日收盤價事後補記買賣。
4. 例假日、國定休市日不能交易。
5. 若當天該執行的時間點遇到**斷線、電腦沒開、程式失敗**，
   則**當天就是沒有交易**，不得於稍晚或隔天以當天的價格追認。
   跟真人錯過盤是一樣的後果。

這條規則的用意是消除**前視偏誤（look-ahead bias）**：
收盤後才決定「今天要買」，等於已經看完全天走勢才下注，
這樣得到的績效是假的，也是最容易被驗證方抓到的作弊型態。

---

## 三、成交價

1. 成交價**一律採用下單當下證交所的即時成交價**。
2. **不得自行指定成交價**，不得使用當日最低價買進、最高價賣出這類事後最佳化價格。
3. 價格來源必須可被第三方驗證（例如證交所 MIS 即時報價、或事後可用公開日線比對，
   成交價須落在當日 最低價 ~ 最高價 區間內）。
4. 每一筆成交都必須記錄：**成交時間戳、價格來源說明**。

---

## 四、交易成本（三方使用相同參數）

| 項目 | 費率 |
|---|---|
| 券商手續費 | 成交金額 × **0.1425% × 0.6折**（電子下單常見折扣），無條件捨去至整數元 |
| 最低手續費 | 每筆 **20 元** |
| 證券交易稅 | 賣出時 成交金額 × **0.3%**，無條件捨去至整數元（買進不課） |

- 買進手續費**滾入持股成本**；賣出的手續費與證交稅**從實收金額扣除**。
- 不模擬滑價與流動性衝擊（三方一致，視為公平）。

---

## 五、可以做什麼、不能做什麼

**可以：**
- 現股買進、賣出（含 ETF）
- 零股交易（最低手續費同樣適用）
- 空手不交易。沒有「每天必須下單」的要求

**不可以：**
- 融資、融券、借券、當沖
- 期貨、選擇權、權證等衍生商品
- 放空
- 買進超過現金餘額（不得透支）
- 交易台股以外的市場（美股、加密貨幣**只能作為判斷依據**，不能持有）

## 六、紀錄要求（可稽核性）

每一筆交易都必須留下：

1. **買進／賣出的理由** —— 為什麼是這檔、為什麼是這個時間點
2. **成本、股數、手續費、稅**
3. **投資論點**：預期的催化劑、目標價、停損價、預計持有期間、什麼情況代表看錯
4. **決定不動也要記錄** —— 只記錄有交易的日子，事後無法分辨「判斷正確」與「根本沒判斷」

另外：
- 帳本與每日紀錄必須**每天提交到 git**（公開 repository）。
  git 的 commit 時間戳就是「這個判斷寫在結果發生之前」的證明。
- 紀錄一旦提交不得回頭修改。修正要用新的紀錄說明，不能覆蓋歷史。

---

## 七、驗證與作弊認定

**帳本會交由其他 AI 交叉驗證。** 以下任一情形視為作弊，立即出局：

1. 成交價與當日公開報價區間不符（買在當日最低、賣在當日最高等事後最佳化）
2. 於休市時段成交，或事後補記交易
3. 竄改、刪除已提交的歷史紀錄
4. 現金／持股計算與交易紀錄無法對帳
5. 買進理由在事後被改寫成符合已知結果的版本
6. 交易超過現金餘額，或違反第五節的商品限制

驗證方應該要能**只拿公開資料 + git 歷史，就把整個帳本從頭重算一次**。
做不到這件事的帳本，本身就是問題。

## 八、資料來源（不限定，僅供參考）

判斷可以用任何公開資訊：新聞、總體經濟數據、財報、籌碼、技術面、其他市場（美股、匯率、原油、加密貨幣）等。

本帳戶使用：
- **FinMind** — 台股日線 OHLCV、法人買賣超、月營收、財報
- **Yahoo Finance** — 加權指數、費半、美債殖利率、匯率、原油、比特幣
- **證交所 MIS** — 盤中即時報價（成交價來源）

## 九、需要委託人確認的細項

以下是本帳戶採用的預設值。若其他參賽者有不同設定，應統一：

- [ ] 手續費折扣 **6 折**（可改為不打折或其他折數，三方須一致）
- [ ] 腰斬判定以**總資產**（現金＋持股市值）計算，非僅看已實現損益
- [ ] 期末結算是否強制平倉？本帳戶預設**以最後交易日收盤市值計算，不強制平倉**
- [ ] 是否允許持有到期末仍虧損的部位（不強制停損）→ 預設**允許**
